# Agents

The conventions for every coding agent are in `CLAUDE.md`. Read it first. It
holds the repository layout, the addon contract, the version rule, the
deployment rule, the coding rules, the test rules, the git identity, and the
workflow. The writing standard is Simplified Technical English. The rules and
a linter are in `.claude/skills/ste-writing/`. `CONTRIBUTING.md` has the fork
and upstream steps. `docs/releasing.md` has the release procedure. This page
repeats none of them.
